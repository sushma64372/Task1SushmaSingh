# Data Cleaning and Preparation – DecodeLabs Internship

## Project Overview

This project focuses on cleaning and preparing a raw dataset for data analysis as part of the DecodeLabs Data Analytics Internship – Project 1.

## Objectives

* Identify and handle missing values.
* Remove duplicate records.
* Correct data formats.
* Validate Order IDs and date formats.
* Prepare a clean dataset for further analysis.

## Tools and Technologies

* Python
* Pandas
* Excel
* Git and GitHub

## Dataset Information

* Total Records: 1200
* Total Columns: 14

## Data Cleaning Process

1. Loaded the raw Excel dataset using Pandas.
2. Checked missing values in all columns.
3. Handled missing CouponCode values by replacing them with "No Coupon".
4. Checked and removed duplicate records.
5. Corrected date formats.
6. Validated Order IDs and dates.
7. Exported the cleaned dataset to Excel.
